Программа генерирует синусоидальный сигнал
частотой  172 Гц на контроллере  esp8266 плата Wemos D1 moni Pro
 
Среда разработки- Ардуино
Метод -плотностная  модуляция.
Частота дескритизации -44100.
Количество точек- 256
Протокол -I2S -плотностная модуляция
Вывод сигнала на пин Rx- платы.

Прослушать сигнал можно через усилитель  низкой частоты  (НЧ).
Для этого собрал ФНЧ -фильтр низких частот из из двух конденсаторов и резистора.
Конденсатор 1- 10uF
Конденсатор 2-10 nF
Резистор          - 1K.

Таким же образом сигнал можно подать и на осцилограф.
