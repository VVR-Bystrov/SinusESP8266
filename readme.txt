# Генtрируем и слушаем  синусоиальный сигнал 172 Гц.
Программа генерирует синусоидальный сигнал
частотой  172 Гц на контроллере  esp8266 плата Wemos D1 moni Pro.
 
Среда разработки- Ардуино.
Метод -плотностная  модуляция.
Частота дискритизации -44100.
Количество точек- 256.
Протокол -I2S -плотностная модуляция.
Вывод сигнала на GPIO  Rx- платы.

Прослушать сигнал можно через усилитель  низкой частоты  (УНЧ).
Для этого  между   Wemos D1 moni Pro и УНЧ ставят  фильтр низкой частоты (ФНЧ).
ФНЧ  состоит из двух конденсаторов и одного резистора.
Конденсатор 1- 10uF
Конденсатор 2-10 nF
Резистор          - 1K.
Схема соединения приведена на рисунке.
Рисунок- файл  Low-pass filter.png

Таким же образом сигнал можно подать и на осцилограф.
