Генерирование синусоидального сигнала
на контроллере  esp8266 плата Wemos D1 moni Pro

Источник
https://www.hackster.io/janost/audio-hacking-on-the-esp8266-fa9464

 ЦАП  генерирует  синусоиду с частотой 172 Гц:
Среда разработки- Ардуино
Метод -плотностная  модуляция.
Частота дескритизации -44100.
Количество точек- 256
Протокол -I2S -плотностная модуляция
Вывод сигнала на пин Rx- платы.
Прослушать сигнал можно через усилитель НЧ.
Для этого вход усилителя зашунтировал резистором на Gnd
А вывод Rx-  соединил со входом усилителя через конденсатор.
Gnd  платы соединить с  Gnd усилителя.
Таким же образом можно подать и на осцилограф.
