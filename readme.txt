Моделирование синуса на esp8266
Плата Wemos D1 moni Pro
Среда разработки Ардуино
Методом плотностной  модуляции.
Берется массив из 256 чисел синуса
Призводится плотностная модуляция  и выводится  при помощи библиотеки i2s 
на два пина ( Rx  и Gnd) контроллера поток битов.
см также статью о синтезаторах
https://www.hackster.io/janost/audio-hacking-on-the-esp8266-fa9464

На виде Осцилограф ЛО-70
Переключатель 9 диапазонов
1- 10-30 гц
2- 25-65 гц
3- 60-220 гц
4- 200-620 гц 
5-  520-2000 гц
6-1,5-6,5 кгц
7- 6,4-15 кгц
8- 14-,9 кгц
9- 36-80 кгц
